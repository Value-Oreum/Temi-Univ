01 / Why Now

화면 속 코드는,
실전 경험이 되지 못합니다

대부분의 SW·AI 교육은 화면 안에서 끝납니다. 산업 현장은 실제 공간에서 이동하고, 사람과 대화하며, 예상치 못한 변수에 반응하는 서비스를 요구합니다.

TEMI 실습 = 코드 작성 → 로봇이
이동·대화·안내까지 수행
01 / Shift

이론과 화면에서, 실제 공간의 경험으로

기존 SW·AI 교육

  • 화면 안에서 끝나는 실습
  • 결과물이 화면 속 코드에 머묾
  • 이론 중심 수업, 약한 성취감
  • 예상치 못한 변수 없는 환경

TEMI 실습

  • 코드가 이동·대화·안내로 이어짐
  • 실제 공간의 변수에 반응하는 서비스
  • 눈앞에서 움직이는 ‘가시적 성취감’
  • 캡스톤 발표·전시용 실물 결과물

이제 필요한 것은 더 많은 이론이 아니라, ‘실제 공간에서 작동하는 경험’입니다.

03 / Reference · 도입 배경

왜 도입했는가

AI·소프트웨어 이론 교육을 넘어, 학생이 직접 개발한 결과물이 실제 공간에서 작동하는 경험을 제공할 실습 기자재가 필요했습니다.

  • 이론 중심 SW 수업의 한계를 보완할 실물 결과물 필요
  • 안드로이드 기반 SDK로 기존 프로그래밍 역량과 바로 연결
  • 캡스톤디자인 등 팀 프로젝트형 수업에 적합한 실습 대상 확보
